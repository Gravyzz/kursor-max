# Сторонние компоненты

Курсор использует пакеты с открытыми лицензиями. Точные версии зафиксированы в `package-lock.json` каждого приложения.

| Компонент | Лицензия |
|---|---|
| Node.js, Fastify, PostgreSQL client, Zod, React, Vite, qrcode | MIT |
| `@maxhub/max-bot-api`, `@maxhub/max-ui` | MIT |
| Caddy | Apache-2.0 |
| PostgreSQL | PostgreSQL License |
| TypeScript | Apache-2.0 |
| Lucide | ISC |
| Onest (`@fontsource/onest`) | SIL Open Font License 1.1 |
| PGlite | Apache-2.0 |
| Playwright | Apache-2.0 |

Тексты лицензий npm-зависимостей устанавливаются вместе с пакетами. Финальная публичная версия не содержит Max Sans или сторонних изображений с неподтверждёнными правами. Интерфейс использует Onest, собственные CSS-градиенты и изображения кампуса, созданные командой проекта с помощью генеративного ИИ специально для «Курсора».
